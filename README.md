## 🎯 Aim

To develop an Interactive FAQ section where clicking a question
displays or hides the corresponding answer using JavaScript DOM
manipulation and event listeners.

---

## 📖 About the Project

The Interactive FAQ Portal is a user-friendly web component that
allows users to click on frequently asked questions to view or hide
their answers.

This project demonstrates how JavaScript can dynamically control
HTML elements without refreshing the webpage.

It is useful for:

- College help portals
- Student support websites
- Documentation pages
- Customer support sections
- Knowledge-base websites

---

## ✨ Features

- 🎨 Attractive modern user interface
- 📱 Responsive design for different screen sizes
- ❓ Multiple FAQ questions
- 🖱️ Click-to-show and click-to-hide answers
- ⚡ No page reload required
- 🔄 Smooth expand and collapse animation
- 🧩 DOM-based interaction
- 🎯 Simple and beginner-friendly JavaScript
- 💻 Works directly in any modern browser
